# Aware — spec-driven client generator

A reusable, reproducible agentic harness that turns a written specification into working client code. A small local messaging system (Python server + Android/Kotlin client + web client) is the example used to evaluate it.

> Status: **shell only.** Structure and conventions are in place; the spec, generator, server and clients are yet to be written. Items marked ☐ below are open.

## Regeneration boundary

Generated code is confined to `clients/*/` (the directories marked with a `.generated` file). Everything outside is hand-written.

To regenerate: _(☐ to be defined — will be one command in Claude Code, e.g. `/generate-client android`)_. See [`generator/README.md`](generator/README.md).

Each generated file carries a header: `GENERATED by the Aware harness from spec <version> — do not edit; change the spec and regenerate.`

## Authorship

| Artifact | Author |

| `spec/`, `DESIGN.md`, `AGENTS.md`, `generator/`, `server/`, `tests/` | Hand-written (human-directed; AI-assisted drafting noted in commits) |
