# 0001 — Web client stack
- Status: accepted (operator, 2026-10-13, via gap-analysis Q18)
- Context: Brief requires a second client in a different language/stack that cannot share source with Android. Context doc asks for a widely adopted, maintainable community stack, documented.
- Decision: React + TypeScript + Vite; Vitest for unit tests, Playwright for UI/E2E and interop driving.
- Consequences: Most widely adopted option and reliably generated by models; Playwright lets the interop suite drive the web client as Alice or Bob.
